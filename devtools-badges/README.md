# Badges in the Elements tool

➡️ **[Open the demo](https://microsoftedge.github.io/Demos/devtools-badges/)** ⬅️

This demo page contains examples for each of the badges that the **Elements** tool of Microsoft Edge DevTools shows next to elements in the DOM tree:

* `view-source`
* `grid`
* `subgrid`
* `flex`
* `ad`
* `scroll`
* `scroll-snap`
* `container`
* `slot`
* `top-layer`
* `media`
* `popover`
* `starting-style`
* `custom-element`

Some badges, such as `media`, are turned off by default. To turn them on, right-click an element in the DOM tree, and then select the badge in the **Badge settings** submenu.

For instructions, see [Badges reference](https://learn.microsoft.com/microsoft-edge/devtools/elements-tool/badges).
