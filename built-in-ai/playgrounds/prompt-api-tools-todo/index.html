Prompt API tool use (todo)

Declare tools for the on-device language model, and see which ones it calls, and with which arguments. The preloaded tools read and change the todo list at the bottom of the page. Tool use requires the Prompt API Tool Use flag at edge://flags. For more information, see Use tools in the Prompt API documentation.
