CSS Mixins & Macros → Desugared CSS

Write CSS that uses the experimental CSS Functions & Mixins features (@mixin, @macro, @result, @contents, @apply) and see the equivalent "desugared" CSS — roughly what you would write by hand if mixins weren't supported.

Pick an example from the dropdown, or edit the source on the left, then press Convert. The tool below is also available standalone at converter-embed.html so it can be embedded in an <iframe> elsewhere.
